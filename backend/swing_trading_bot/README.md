# Swing Trading Bot

A lightweight swing trading bot skeleton for downloading price data, detecting candlestick patterns, generating trade signals, and backtesting a strategy.

## Structure

- `data/` - cached price data and results
- `src/` - source modules for data loading, indicators, strategy, and backtesting
- `notebooks/` - analysis notebook
- `config.py` - project settings
- `main.py` - pipeline entrypoint
- `requirements.txt` - Python dependencies

## Quickstart

1. Create a virtual environment
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python main.py`
